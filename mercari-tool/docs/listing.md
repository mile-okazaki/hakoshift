# 出品手順

> ⬜ **未記入。** ここに出品作業の手順を追記してください。

## 前提

**ツールはメルカリへの投稿を行いません。** 自動出品は利用規約の禁止事項のため、
最後の投稿操作は人が行います。ツールは貼るだけの状態まで用意します。

## 手順の枠

1. 商品を登録する
   ```bash
   python -m mercari_tool product add --sku ... --name ... --cost ...
   ```
2. 写真を撮って `photos/` に入れる（→ [撮影マニュアル](photography.md)）
3. ドラフトを生成する
   ```bash
   python -m mercari_tool draft <SKU> --photos-dir photos --whiten
   ```
4. `data/output/<SKU>/listing.txt` を開く
5. メルカリアプリで出品画面を開き、以下を貼る

   | 出品画面の項目 | listing.txt の該当箇所 |
   |---|---|
   | 商品の写真 | `images/` の中身。`_thumbnail.jpg` を1枚目に |
   | 商品名 | ① タイトル |
   | 商品の説明 | ④ 商品の説明 |
   | カテゴリー | ③ カテゴリ |
   | 商品の状態 | ③ 商品の状態 |
   | 配送方法 | ③ 配送方法 |
   | 販売価格 | ② 価格 |

6. 内容を目視で確認して出品する
7. 売れたら記録する
   ```bash
   python -m mercari_tool sales add --sku <SKU> --price <売れた価格> --sync
   ```

## 出品前に必ず確認すること

> ⬜ ここに記入してください。想定される項目:
>
> - ドラフトに出た `⚠` の警告をすべて解消したか
> - 写真と説明文で、傷の申告が一致しているか
> - タイトルの語が、実際の商品に当てはまるか
