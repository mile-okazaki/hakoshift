# 出品手順

> ✏️ このマニュアルはツールの仕様に合わせた標準手順です。
> 運用に合わせて書き換えて構いません。

## 前提

**ツールはメルカリへの投稿を行いません。** 自動出品は利用規約の禁止事項のため、
最後の投稿操作は人が行います。ツールは貼るだけの状態まで用意します。

## 手順

1. 商品を登録する（複数あるなら仕入れ表からまとめて）
   ```bash
   python -m mercari_tool product add --sku ... --name ... --cost ...
   # まとめて登録する場合
   python -m mercari_tool product import shiire.csv --dry-run   # まず確認
   python -m mercari_tool product import shiire.csv
   ```
2. 相場を書き写す（メルカリで同じ商品を検索し、**売り切れ**で絞り込んで
   直近の成約価格を10件ほど打つ）
   ```bash
   python -m mercari_tool research add --sku <SKU> --prices 9800,11500,8900,10200
   ```
3. 写真を撮って `photos/` に入れる（→ [撮影マニュアル](photography.md)）
4. ドラフトを生成する
   ```bash
   python -m mercari_tool draft <SKU> --photos-dir photos/<SKU> --whiten
   # 溜まったぶんをまとめて
   python -m mercari_tool draft --all --in-stock --photos-root photos --whiten
   ```
5. `data/output/<SKU>/listing.txt` を開く
6. メルカリアプリで「出品」を開き、以下を貼る

   | 出品画面の項目 | listing.txt の該当箇所 |
   |---|---|
   | 商品の写真 | `images/` の中身。`_thumbnail.jpg` を1枚目に、残りを番号順に |
   | 商品名 | ① タイトル |
   | 商品の説明 | ④ 商品の説明（ハッシュタグ込みでそのまま） |
   | カテゴリー | ③ カテゴリ |
   | 商品の状態 | ③ 商品の状態 |
   | 配送の方法 | ③ 配送方法 |
   | 販売価格 | ② 価格 |

   タイトルがしっくりこない場合は、listing.txt 末尾の
   「タイトル候補（差し替え用）」から選び直せます。
7. 内容を目視で確認して、**出品ボタンを押す**（下のチェックリスト参照）

## 出品前チェックリスト

出品ボタンを押す前に、必ず次を確認します。

- [ ] ドラフト生成時に出た `⚠` の警告をすべて確認したか
      （相場データなし・写真不足・赤字警告は、そのまま出品しない）
- [ ] 写真の1枚目は商品全体が写っているか
- [ ] **写真・説明文・商品の状態欄で、傷の申告が一致しているか**
      （説明に書いた傷が写真に写っているか。写真の傷が説明にあるか）
- [ ] タイトルの語がすべて実物に当てはまるか
      （相場から拾った語が混ざるため、最終確認は人が行う）
- [ ] 価格が仕入値を下回っていないか（`price suggest` の損益分岐を下回る
      価格を手で付けない）
- [ ] カテゴリ・配送方法がアプリ側の選択肢と一致しているか

## 出品後にやること

- **コメントが来たら**: 返信文を作らせてから、内容を確認して送る
  ```bash
  python -m mercari_tool comment <SKU> --text "値下げできますか？"
  ```
- **値下げ交渉が来たら**: 応じてよい金額かを先に判定する
  ```bash
  python -m mercari_tool price offer <SKU> <提示された金額>
  ```
- **売れたら**: その日のうちに記録する（集計とシート反映のため）
  ```bash
  python -m mercari_tool sales add --sku <SKU> --price <売れた価格> --sync
  ```
- 発送・評価はアプリ側で通常どおり行います。

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| listing.txt が見つからない | `data/output/<SKU>/` を確認。`--out` を指定した場合はそちら |
| タイトルが40文字を超えて貼れない | ツールは40字に収めて出すため、手で語を足した場合のみ起こる。候補から選び直す |
| 説明文が味気ない | APIキー未設定時はテンプレート組み立て。`.env` に `ANTHROPIC_API_KEY` を設定すると生成に切り替わる |
| 価格に自信がない | `python -m mercari_tool price suggest <SKU>` で3案と根拠を見る |
