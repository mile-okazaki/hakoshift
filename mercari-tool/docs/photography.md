# 撮影マニュアル

> ✏️ このマニュアルはツールの仕様に合わせた標準手順です。運用に合わせて
> 書き換えて構いませんが、「ファイル名」「枚数」「置き場所」の項目は
> ツールの動作に直結します。変えたい場合は先にツール側を直してください。

## 置き場所とファイル名（ツールの動作に関わる）

**ファイル名の昇順がそのまま掲載順**になります。撮影順に番号を振ってください。

1点だけ処理する場合（`--photos-dir`）:

```
photos/
  01_正面.jpg      ← 1枚目（サムネイルの元になる）
  02_背面.jpg
  03_タグ・型番.jpg
  04_ソール・底面.jpg
  05_傷の箇所.jpg
```

まとめて処理する場合（`draft --all --photos-root photos`）は **SKUごとのフォルダ**に:

```
photos/
  NK-AM90-27/
    01_正面.jpg
    02_背面.jpg
    ...
  UQ-FL-M/
    01_正面.jpg
    ...
```

- 1枚目は必ず**商品全体が写った正面写真**。サムネイルはこの写真から作られます。
- 対応形式: jpg / jpeg / png / webp / **heic**（iPhoneそのままでOK）/ heif / bmp / tif
- スマホからPCへは AirDrop・Googleフォト・ケーブルなど何でも構いません。
  リネームは PC 側でまとめて行うのが速いです。

## 枚数（ツールの動作に関わる）

- 上限は **10枚**（メルカリの上限）。超えた分は使われず、警告が出ます。
- **4枚未満だと警告**が出ます。最低限そろえるのは次の4枚です。

| 番号 | 内容 | ねらい |
|---|---|---|
| 01 | 正面全体 | 検索一覧で目に入る1枚。サムネイルの元 |
| 02 | 背面・側面 | 全体の状態確認。問い合わせを減らす |
| 03 | タグ・型番・サイズ表記 | 正規品・サイズの根拠。偽物疑いのコメントを防ぐ |
| 04 | 傷・汚れの箇所（寄り） | クレームと悪い評価の予防。**必ず撮る** |

## 撮り方

- **背景は無地**にします（白い壁・机・白布・模造紙など）。`--whiten` は
  「四隅から連続した均一な背景」を白く飛ばす仕組みなので、柄物の背景や
  ごちゃついた床では効きません。
- **被写体を画面端に接しさせない**でください。四隅が背景でつながっている
  ことが背景検出の前提です。余白は自動で切り詰められるので、広めに引いて
  撮って構いません。
- **昼間の窓際の自然光**がいちばん失敗しません。直射日光と強い逆光は避けます
  （白飛び・黒つぶれは自動補正でも戻せません）。
- **ピントだけは撮影時にしか直せません。** タグ・型番・傷の寄り写真は
  撮った直後に拡大して確認してください。
- **傷は隠さず、いちばん分かりやすく撮ります。** 商品マスタの「難点」に
  登録した内容と写真は必ず一致させてください。申告した傷の写真が無い、
  逆に写真にある傷が未申告、のどちらも取引トラブルの元です。
- **使ってはいけない加工**: 色味を変えるフィルタ、美肌系アプリ、傷を消す
  レタッチ。実物と違う写真は「イメージと違う」による返品・低評価に直結し、
  規約上も問題になります。明るさ・余白・背景処理はツールに任せてください。

## ツール側で自動的にやること（撮影時に気にしなくてよいこと）

| 項目 | ツールの処理 |
|---|---|
| 写真の向き | EXIFの回転情報を反映して自動で正します |
| 余白 | 周囲の均一な余白を自動で切り詰めます |
| 明るさ・色かぶり | 自動補正します（色相は変えません） |
| 正方形化 | 足りない部分を白で埋めます。被写体は切りません |
| サイズ | 長辺1080pxまで縮小します（拡大はしません） |

つまり撮影時に人が担保するのは **「ピント」「無地の背景」「傷を全部写す」** の
3つだけです。構図の細かい調整に時間をかける必要はありません。
