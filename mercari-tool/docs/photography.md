## ファイル名の付け方（ツールの動作に関わる）

`--photos-dir` を使う場合、**ファイル名の昇順がそのまま掲載順**になります。
撮影順に番号を振ってください。

```
photos/
  01_正面.jpg      ← 1枚目（サムネイルの元になる）
  02_背面.jpg
  03_タグ・型番.jpg
  04_ソール・底面.jpg
  05_傷の箇所.jpg
```

1枚目は必ず商品全体が写った正面写真にしてください。サムネイルはこの写真から作られます。

## 枚数（ツールの動作に関わる）

- 上限は **10枚**。超えた分は使われず、警告が出ます。
- **4枚未満だと警告**が出ます。正面・背面・タグ・傷の箇所は最低限あると
  問い合わせが減ります。

## 撮り方

> ⬜ ここに記入してください。想定される項目:
>
> - 背景（ツールの `--whiten` は、四隅から連続した均一な背景を白く飛ばします。
>   無地の壁・机・白い布などで撮ると効果的です）
> - 明るさ（ツール側で自動補正しますが、極端な逆光は補正しきれません）
> - 傷の写し方
> - 使ってはいけない加工

## ツール側で自動的にやること（撮影時に気にしなくてよいこと）

| 項目 | ツールの処理 |
|---|---|
| 写真の向き | EXIFの回転情報を反映して自動で正します |
| 余白 | 周囲の均一な余白を自動で切り詰めます |
| 明るさ・色かぶり | 自動補正します（色相は変えません） |
| 正方形化 | 足りない部分を白で埋めます。被写体は切りません |
| サイズ | 長辺1080pxまで縮小します（拡大はしません） |
