## 書くときの注意

ツールの挙動と食い違うと現場が混乱するので、以下はツール側の仕様に合わせてください。
仕様を変えたい場合は先にツールを直します。

| 項目 | ツール側の仕様 | 根拠 |
|---|---|---|
| 写真の枚数 | 最大10枚。4枚未満で警告 | メルカリの上限。少ないと問い合わせが増える |
| 写真の並び | `--photos-dir` はファイル名の昇順 | `01_正面.jpg` のように付ければ撮影順＝掲載順 |
| 写真の置き場所 | 一括処理は `photos/<SKU>/` を見る | `draft --all --photos-root photos` |
| 相場の記録 | `research add` で貯める。同じ行は重複登録されない | `data/comps/<検索語>.json` に追記 |
| 商品の一括登録 | `product import` は既存SKUを**更新**（空欄で消さない） | 在庫だけのCSVで在庫更新ができる |
| 写真の形式 | jpg / jpeg / png / webp / heic / heif / bmp / tif | `cli.py` の `PHOTO_SUFFIXES` |
| 出力サイズ | 正方形。長辺1080まで縮小、拡大はしない | 画質劣化を避けるため |
| タイトル | 40文字以内 | メルカリの上限 |
| 説明文 | 1000文字以内 | メルカリの上限 |
| 最低価格 | 300円 | メルカリの下限 |
| 投稿操作 | **ツールは行わない。人がアプリで行う** | 自動出品は利用規約の禁止事項 |
